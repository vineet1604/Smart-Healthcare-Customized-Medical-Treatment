
# Smart Healthcare & Customized Medical Treatment

A Machine Learning and Flask-based healthcare recommendation platform that predicts diseases based on user symptoms and provides personalized healthcare recommendations including precautions, medications, diet plans, and workout suggestions.

The system is designed to assist users in understanding possible health conditions through an interactive dashboard and symptom-based disease prediction model.

---

## 🚀 Project Features

### Disease Prediction
Predicts potential diseases based on symptoms entered by the user using a trained Machine Learning model.

### Personalized Recommendations
Provides:
- Disease Description
- Precautions
- Medication Suggestions
- Diet Recommendations
- Workout Recommendations

### Speech Recognition
Users can provide symptoms using voice input, improving accessibility and user experience.

### Symptom Processing
- Synonym Mapping
- Auto-Spelling Correction
- Symptom Normalization
- Input Validation

### Interactive Dashboard
A responsive healthcare dashboard built using Flask, HTML, CSS, Bootstrap, and JavaScript.

## 📋 System Workflow

1. User enters symptoms manually or through voice input.
2. Symptoms are cleaned and processed.
3. Synonym mapping and spelling correction are applied.
4. The trained Machine Learning model predicts the disease.
5. The system displays:
   - Predicted Disease
   - Description
   - Precautions
   - Medications
   - Diet Recommendations
   - Workout Suggestions
